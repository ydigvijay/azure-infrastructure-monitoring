# Azure Infrastructure Monitoring — Screenshots

This directory contains visual evidence of the implementation and testing of the Azure Infrastructure Monitoring project.

The screenshots will demonstrate Azure infrastructure deployment, RHEL system administration, monitoring configuration, and alerting.

## Screenshots

### 1. Azure Virtual Machine Overview
**Filename:** `vm-overview.png`

Shows the deployed RHEL virtual machine in the Azure Portal, including its resource status and configuration.

### 2. RHEL Linux Health Check
**Filename:** `linux-health-check.png`

Shows the output of the Bash health-check script, including operating system details, uptime, CPU activity, memory usage, disk utilization, and failed services.

### 3. Azure Monitor Metrics
**Filename:** `azure-monitor-metrics.png`

Shows the CPU utilization graph and other available infrastructure metrics for the virtual machine.

### 4. CPU Alert Configuration
**Filename:** `cpu-alert-rule.png`

Shows the Azure Monitor metric alert rule configured to detect high CPU utilization.

### 5. Alert Notification
**Filename:** `alert-notification.png`

Shows an alert notification received after the configured alert condition was triggered and tested, if applicable.
